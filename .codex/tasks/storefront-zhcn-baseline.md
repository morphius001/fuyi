# Task: storefront-zhcn-baseline

## Goal

完成 `apps/storefront` 基础中文化和国内本地生鲜/海鲜多商户前台风格改造。保持低风险，不改后端业务逻辑。

## Read First

- `AGENTS.md`
- 本文件 `.codex/tasks/storefront-zhcn-baseline.md`
- `apps/storefront` 下现有 README、配置和路由结构

## Allowed Changes

- `apps/storefront/**`

## Forbidden Changes

- 禁止修改 `packages/api/**`
- 禁止修改 `apps/admin/**`
- 禁止修改 `apps/vendor/**`
- 不接真实微信支付
- 不接真实支付宝
- 不接真实客服
- 不接真实物流
- 禁止修改支付、订单、退款、结算、佣金、权限业务逻辑
- 禁止写真实密钥
- 不要自动提交
- 不要 push

## UX Requirements

- 中文文案：面向中国大陆消费者，默认 zh-CN。
- 人民币：价格展示使用 CNY/人民币语境。
- 平台定位：可切换市场的本地生鲜海鲜、水果蔬菜多商户平台，以市场、店铺/档口和今日鲜货为核心，不做普通通用商城首页。
- 市场入口：顶部或首屏体现市场选择/切换，示例可用“三门海鲜市场”，但文案不要写死单市场。
- 搜索：强化搜索入口，支持搜索商品、店铺、档口、市场、类目。
- 分类：鲜活水产、冰鲜冻品、海产干货、水果蔬菜、本地热卖、今日到货、提货卡提货等。
- 店铺卡：突出店铺名、市场、档口号、主营类目、营业状态、配送/自提能力、认证/评分。
- 商品详情：强化价格、今日价、库存、规格、鲜活/冰鲜/冷冻标签、配送、自提、售后、保障说明。
- 直播入口：可预留今日鲜货直播、市场直播、店铺/档口直播、直播商品推荐和回放入口；只做 UI 占位，不接真实直播、IM、推流或支付。
- 购物车：中文化商品、优惠占位、配送和结算入口。
- 结算页：中文化地址、配送、支付方式占位和订单确认。
- 订单状态：使用中国大陆电商常见状态文案。
- Footer 合规占位：公司信息、ICP备案占位、隐私政策、用户协议、售后服务、联系客服。
- 提货卡消费者路径：输入卡号/卡密/扫码后，系统识别可提权益，用户确认提货内容、地址或自提时间，提交提货申请。不要做成用提货卡购物、支付、抵扣、余额或优惠券。
- 市场物料采购不作为普通消费者主链路展示；泡沫箱、冰袋、冰块等属于商户端 B 端能力。
- 可展示“产地直供/认证商户/市场档口”等消费者信任标签，但不要暴露上游采购工作台。

## Integration Constraints

- 支付成功必须以后端异步通知为准。
- 前台支付返回页不得作为支付成功依据。
- 微信支付、支付宝、客服、物流只做占位或 mock 文案，不接真实服务。
- 不要删除 Stripe、Algolia、Resend、TalkJS。
