# Task: vendor-shell

## Goal

把 `apps/vendor` 改造成中国大陆商户/供应方经营工作台基础版。不只是翻译，要强化商户后台壳，形成适合可切换市场、本地生鲜海鲜、水果蔬菜、市场物料、上游货源和配送供应商日常运营的信息架构和页面骨架。

## Read First

- `AGENTS.md`
- 本文件 `.codex/tasks/vendor-shell.md`
- `apps/vendor/CLAUDE.md`
- `apps/vendor/src/README.md`

## Allowed Changes

- `apps/vendor/**`

## Forbidden Changes

- 禁止修改 `apps/admin/**`
- 禁止修改 `apps/storefront/**`
- 禁止修改 `packages/api/**`
- 禁止修改支付、订单、退款、结算、佣金、权限业务逻辑
- 不接真实 API
- 不实现真实发货、退款、结算
- 禁止写入真实密钥
- 不要自动提交
- 不要 push

## Shell Requirements

- 保留现有商户后台认证、Provider、ProtectedRoute 和权限边界。
- 不要绕过商户身份、订单归属、结算和权限控制。
- 可以在现有扩展机制内实现中国大陆商户后台壳。
- 默认示例可以使用“三门海鲜市场”，但不要写死单一市场；界面要体现市场可切换、商户可跨市场经营。
- 当前阶段只做 mock/placeholder UI，不实现真实角色权限、模块开关、订单、采购、配送或结算行为。

## Product Context

- 普通经营商户：海鲜档口、冻品商户、干货商户、水果蔬菜商户。
- 独立供应方：物料供应商、配送供应商、养殖户、种植户、种苗供应商、外地批发商。
- 商户属于市场，商户有档口号/市场位置，一个商户可以跨多个市场。
- 市场有自己的配送规则、营业时间、公告、自提规则和服务范围。
- 市场物料采购只面向商户，不面向普通消费者；允许物料供应商自己接单。
- 上游货源以采购需求、报价、合作关系、到货/到苗计划为主，不要做成消费者购买链路。
- 手机端快速上架和 AI 一句话上架必须先产生草稿/占位预览，后续真实实现必须由商户确认后再上架。
- 快递打印/电子面单先做物流管理 mock/placeholder，不接真实快递100、菜鸟、顺丰、京东物流或云打印，不生成真实运单号，不真实确认发货或修改订单状态。
- 直播先做 mock/placeholder，适合今日鲜货直播、档口直播、直播商品讲解和回放管理；不接真实直播、IM、推流、支付或直播订单。

## Home Metrics

首页指标应偏商户日常经营视角，可使用 mock 或只读占位数据：

- 今日成交额
- 今日订单数
- 待发货订单
- 待处理售后
- 在售商品数
- 库存预警
- 未读客服消息
- 待结算金额
- 店铺评分
- 当前市场/档口号
- 市场公告
- 市场配送规则/营业时间摘要
- 手机快速上架待补商品
- AI 上架草稿
- 物料库存预警
- 上游报价待确认
- 到货/到苗计划

必须明确 mock/placeholder 数据来源，不要伪装为真实 API 数据。

## Required Placeholder Areas

- 市场上下文：市场切换、档口号、多市场经营提示、市场公告、配送规则、营业时间。
- 店铺装修：店铺主页、头图、公告、商品分组、今日鲜货、资质展示、配送说明、预览店铺。
- 手机快速上架：今日鲜货快速上架、常卖商品模板、今日价批量更新、拍照补货占位。
- AI 一句话上架：输入示例、解析结果草稿、确认上架占位、风险提示。
- 直播经营：开播占位、直播商品、直播公告、回放管理、直播咨询/订单占位；只做 mock。
- 快递打印/电子面单：待打印订单、面单预览、打印机设置、打印记录、批量打印按钮；只做 mock，不调用真实物流。
- 市场物料：泡沫箱、包装箱、冰袋、冰块、周转筐、胶带、标签、常用采购清单、物料订单。
- 物料供应商工作台：供货商品、物料订单、报价、服务市场；只做 mock。
- 配送供应商工作台：配送服务、配送订单、异常处理、服务范围；只做 mock。
- 上游货源：养殖户、种植户、种苗批发、外地批发商、采购需求、报价单、合作对象、到货/到苗计划。
- 合规资质：营业执照、食品经营许可、产地证明、检测报告、冷链资质、配送资质、种苗经营资质等状态占位。

## Page Skeleton Requirements

每个页面骨架应包含：

- 中文标题
- 简短业务说明
- 关键指标或状态筛选
- 空状态
- 错误或禁用状态说明
- 后续接真实 API 的 TODO 或注释，保持简洁

页面骨架不得执行真实发货、退款、结算、库存扣减或权限变更。

## Verification

优先运行：

```bash
bun --cwd apps/vendor run lint
bun --cwd apps/vendor run build
```

如任务影响共享类型或根配置，再运行：

```bash
bun run lint
bun run check-types
```

手动验证：

- Vendor 登录/保护路由仍由现有外层处理。
- 所有一级菜单可访问或有明确占位。
- 不存在真实发货、退款、结算调用。
- 商户权限和订单归属边界未改动。
- 市场物料、上游货源、供应方工作台明确为 mock/placeholder。
- 手机快速上架和 AI 上架不执行真实上架。
- 快递打印/电子面单不生成真实运单、不调用物流 API、不修改订单状态。
