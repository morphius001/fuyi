```text
市场经营 / 我的能力边界
```

## 范围

本轮只修改 Vendor 前端展示：

- 新增导航项“我的能力边界”。
- 新增专用只读面板和静态合同数据。
- 展示角色与市场归属、快速上架、规格模板、AI 草稿、店铺装修、履约/面单、提货卡和直播边界。
- 不新增后端 route。
- 不新增保存、发布、发货、打印、开播、兑换或结算动作。

## 安全边界

本页不是：

- 权限开关。
- 商品发布入口。
- 真实库存入口。
- 真实发货或面单入口。
- 提货卡兑换入口。
- 直播交易入口。
- 支付、订单、退款、结算、佣金、打款或权限事实来源。
