# Vendor Role Workspace Template V2

更新时间：2026-05-08 Asia/Shanghai

## 目标

本轮把 Vendor 首页补成角色工作台模板 v2 的只读预览，让不同商户角色的工作重点在首页就能分清楚。它是商户端展示层改造，不是权限、接单、履约、结算或支付能力。

## Template ID

```text
vendor-role-workspace-v2
```

## 本轮改动

- 首页新增“角色工作台模板 v2”区块。
- 新增普通生鲜/海鲜商户、水果蔬菜商户、物料供应商、配送供应商、养殖户/种植户、种苗供应商和外地批发商的只读角色卡片。
- 每个角色卡片展示当前状态、工作重点、可查看的占位入口和禁止边界。
- 保留 `vendor-role-workspace-v1` 或旧商户首页作为回滚方向。

## 明确边界

- 普通商户可见商品、订单、售后、手机快速上架和店铺装修，但本轮不写库存、不发布商品、不改订单状态。
- 水果蔬菜商户突出规格、单位、产地、批次、采摘日和保鲜状态，但不把规格模板写死进商品模型。
- 物料供应商面向商户采购，不进入普通消费者首页，不触发真实支付或结算。
- 配送供应商只展示服务市场、服务范围、运力和异常，不确认发货、不生成真实面单、不回写物流。
- 养殖户/种植户、种苗供应商和外地批发商是上游供给方，不直接进入消费者主链路，不创建真实采购、库存、支付或结算。
- 手机快速上架和 AI 一句话上架仍只能生成草稿或审核候选，必须商户确认后才能进入后续真实任务。

## 风险与回滚

- 风险：展示层增加了首页信息密度，需要后续浏览器人工确认是否太拥挤。
- 回滚：删除新增角色工作台区块和 `vendorRoleWorkspaceCards` 数据即可恢复上一版 Vendor 首页；本轮不改 API、数据库、真实订单、履约、结算或权限。
