# China Live Commerce Read Model

Unregistered, read-only skeleton for China-local live commerce status views.

Boundaries:

- No Medusa module registration.
- No API routes.
- No migrations.
- No MockLiveProvider calls.
- No real streaming, IM, chatroom, gifts, tipping, live order, payment, refund, settlement, commission, payout, permission, or fulfillment behavior.
- Live status is a shop/stall display signal, not a consumer home primary entry.
