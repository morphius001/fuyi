# China Logistics Read Model

Unregistered, read-only skeleton for China-local logistics and waybill capability views.

Boundaries:

- No Medusa module registration.
- No API routes.
- No migrations.
- No checkout shipping option changes.
- No fulfillment creation.
- No real shipment, tracking number, label, cloud print, cancellation, or provider callback.
- No order, payment, refund, settlement, commission, payout, permission, or fulfillment behavior changes.
