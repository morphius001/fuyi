# China Market Read Model Skeleton

This is an unregistered skeleton for China-local market discovery data.

Boundaries:

- No Medusa module registration.
- No database migration.
- No API routes.
- No checkout or shipping option behavior.
- No order, payment, refund, settlement, commission, permission, or fulfillment changes.

It models market, seller membership, seller role, announcements, business hours, and delivery profile data so later PRs can introduce real persistence and read-only APIs in smaller steps.
