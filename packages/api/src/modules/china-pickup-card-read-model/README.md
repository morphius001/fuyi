# China Pickup Card Read Model

Unregistered, read-only skeleton for China-local pickup card consumer flow views.

Boundaries:

- No Medusa module registration.
- No API routes.
- No migrations.
- No real card numbers, secrets, QR tokens, redemptions, or fulfillment orders.
- No checkout, cart, order, payment, refund, settlement, commission, payout, permission, or fulfillment behavior changes.
- Pickup cards are entitlement credentials, not coupons, payment methods, stored value, balances, or cart discounts.
