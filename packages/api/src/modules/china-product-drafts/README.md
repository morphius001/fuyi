# China Product Drafts Skeleton

This folder contains a mock-only, unregistered skeleton for China-local Vendor product drafts.

Boundaries:

- It does not register a Medusa module.
- It does not add API routes.
- It does not create Medusa products.
- It does not initialize inventory.
- It does not publish listings.
- It does not change orders, payments, refunds, settlements, commissions, permissions, or fulfillment.

The skeleton exists so later PRs can add a real module, migrations, API routes, and Vendor UI integration in small reviewed steps.
