# China Shop Decoration Read Model

Unregistered, read-only skeleton for China-local shop and stall decoration.

Boundaries:

- No Medusa module registration.
- No API routes.
- No migrations.
- No decoration draft saving or publishing.
- No real file upload, CDN, live streaming, IM, SMS, logistics, or waybill provider.
- No product, inventory, checkout, order, payment, refund, settlement, commission, payout, permission, or fulfillment behavior changes.
